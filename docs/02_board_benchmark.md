# B1~B7 보드 벤치마크 — 실행 절차와 기록값

> **이 문서의 성격**
> 보드 실측 **원시 로그(콘솔 출력·`-o` CSV)는 저장소에 보관되어 있지 않다.**
> 아래 «기록값» 은 측정 당시의 값을 README §5–6 과 `src/make_figures.py` 의
> 하드코딩 배열(`el`, `wait`)에서 옮겨 정리한 것이며, 이 저장소만으로는
> 재검증할 수 없다. 보드가 있는 경우 아래 절차로 재측정해 대조할 수 있다.
>
> 일부 실행 파라미터(B4 의 챔버 수, B6 의 반복 횟수)는 기록이 남아 있지 않아
> «미기록» 으로 표시했다. 추정값을 적지 않는다.

- 대상: Nextchip APACHE6 SOM (Cortex-A65AE, 1.21 GB RAM)
- 바이너리: `vm_master_a53` / `vm_master_a65` (`make both`)
- 데이터: `replay/` 88 웨이퍼 → **반드시 로컬 tmpfs 로 복사** (§6-② / B-0)

## B-0. 사전 준비 — 데이터를 로컬로 옮긴다

NFS 상태에서 측정하면 I/O 가 99.7% 를 차지해 다른 모든 효과가 묻힌다.

```bash
cp -r ./replay /tmp/replay
```

| 저장 위치 | 경과 | 순수 연산 | 연산 비중 | 샘플당 |
|---|---|---|---|---|
| NFS | 0.596 s | 1.8 ms | 0.3% | 101 ns |
| 로컬 tmpfs | 0.012 s | 1.8 ms | 15.0% | 102 ns |

**50배 차이인데 샘플당 처리시간은 불변** — 병목이 연산이 아니라 데이터 경로임을 보이는 통제 실험이다.

## B1. 이식 정확성 — PC 대비 오차

```bash
# PC(x86) 기준값 생성
make native
./vm_master_native -d ../replay -c 1 -o pc.csv

# 보드
./vm_master_a53 -d /tmp/replay -c 1 -o board.csv
```

> 모델이라 원래 값이 다르다. 대조 기준은 **전체학습 모델 예측인 `pred_full`** 이다.
> (README §9-9)

| 항목 | 기록값 |
|---|---|
| 예측 깊이 최대 오차 | **1.0×10⁻⁵ µm** (RMSE 0.1505 의 1/15,000) |
| 불확실성 `sd` 최대 오차 | 5.3×10⁻⁷ |
| 누적 샘플 수 `n_acc` | **88 / 88 일치** |
| 판정 분포 | PC 와 완전 일치 |

## B2. 챔버 수 스윕 — 물리 코어 수 추정

```bash
for C in 1 2 4 8 16 32; do
```

| C | 경과 [s] | 가속비 | 샘플당 [ns] |
|---|---|---|---|
| 1 | 0.435 | 1.00× | 100 |
| 2 | 0.231 | 1.88× | — |
| **4** | 0.132 | **3.30×** | 106 |
| 8 | 0.117 | 3.72× | 150 |
| 16 | 0.115 | 3.78× | — |

## B3. 실시간 5 Hz 마감 준수

```bash
for C in 1 4 8 16; do
    ./vm_master_a53 -d /tmp/replay -c $C -r -n 10
done
```

`-n 10` 으로 웨이퍼당 샘플을 10개로 제한한다 → 88 웨이퍼 × 10 = **880 샘플**이
마감 판정 모수가 된다.

| 항목 | 기록값 |
|---|---|
| 마감 초과 | **0 / 880** (C = 1·4·8·16 전부) |

> [`run_bench.sh`](../vm_board/run_bench.sh) 의 `[3]` 절에는 `-n` 이 없다. 그대로 돌리면
> 웨이퍼당 3,245 샘플 × 0.2 s ≈ 649 초가 걸려 실측과 맞지 않는다. 기록된 모수
> 880 = 88 × 10 이므로 실제 측정은 `-n 10` 을 붙여 수행한 것이다. 스크립트를
> 그대로 쓰려면 이 옵션을 추가할 것.

> **이 실험이 측정한 것과 아닌 것**
> ① 판정에는 누적 24 샘플이 필요하므로 `-n 10` 에서는 **판정이 발생하지 않는다.**
>    B3 은 마감 준수만 측정하며 판정 결과는 포함하지 않는다. (README §10-7)
> ② 미스 판정 기준은 [`vm_master.c`](../vm_board/vm_master.c) 의
>    `else if (now - next > period)` 로, **한 주기(200 ms)를 통째로 초과한 경우만**
>    센다. 따라서 "0/880" 은 "어떤 샘플도 한 주기 이상 늦지 않았다"는 뜻이며,
>    "모든 샘플이 정확히 200 ms 안에 처리됐다"보다 약한 명제다.

## B4. 세마포어 경합 — 동시 판정 한도 K

```bash
for K in 1 2 4 8; do
    ./vm_master_a53 -d /tmp/replay -c 8 -k $K       # 챔버 8개 고정
done
```

> 챔버 수 8 고정은 [`run_bench.sh`](../vm_board/run_bench.sh) 의 `[4]` 절에 그대로 남아 있다.

| K | 대기시간 평균 [ns] |
|---|---|
| 1 | 34,258 |
| 2 | 7,872 |
| **4** | **4,634 ← 포화** |
| 8 | 4,668 (개선 없음) |

**B2 와 독립적인 두 번째 실험이 같은 "4" 를 가리킨다.** SMT 스레드는 처리량도
동기화 병목도 해소하지 못한다.

> **주의 — 이 값은 구현 변경 전에 측정됐다.**
> 측정 당시 코드는 카운팅 세마포어(GATE) 하나로 결과 버퍼까지 보호했다.
> 현재는 버퍼 뮤텍스(`VM_SEM_BUF`)가 분리돼 있고, 뮤텍스 대기는 `sem_wait_ns`
> 집계 밖에 있으므로 **B4 의 측정 의미는 동일하게 유지된다.**

## B7. 컴파일 타깃 — 벤더 SDK 설정 결함

SDK 는 ARMv8.0(A53) 타깃으로 빌드하나 실제 칩은 ARMv8.2(A65AE)다.
`asimddp`(INT8 내적)·`fphp`(FP16)가 미사용 상태다.

```bash
make both      # a53 / a65 두 개 생성
./vm_master_a53 -d /tmp/replay -c 1
./vm_master_a65 -d /tmp/replay -c 1
```

| 타깃 | 샘플당 [ns] |
|---|---|
| a53 (`-mcpu=cortex-a53`) | 101.2 |
| a65 (`-march=armv8.2-a+dotprod+fp16`) | 99.4 |

**산포(98~106 ns) 이내 — 유의차 없음.** 배정도 스칼라 연산이라 벡터 확장을
활용할 여지가 없다. 이 결함은 CNN 추론 등 벡터 워크로드에서만 문제가 된다.

## 부록. PVT 센서 오독에 의한 강제 정지

지속 부하(B6) 중 시스템이 halt 됐다.

```
Critical: [VISION_Temp] 3379.4 C exceeds maximum 125 C limit.
System will halt now.
```

3379.4 °C 는 물리적으로 불가능하며, 동시각 `hwmon0/temp1` 은 48 °C 였다.
벤더 감시 데몬과 사용자 스크립트가 동일 PVT 를 동시 폴링한 상황이었고,
PVT 컨트롤러의 "채널 선택 → 값 읽기" 2단계 접근에서 경쟁 상태가 발생한 것으로
보인다.

> 차량용 SoC 의 열 보호 로직이 센서 계측 신뢰성에 그대로 의존한다는 실무적
> 함의가 있다. 이후 PVT 는 **부하 전후 단발 읽기만** 사용했다. (README §9-12)

## 판정 지연 예산 — 왜 더 최적화하지 않는가

지연 목표는 취향이 아니라 **모델 오차로부터 물리적으로 유도된다.**

```
모델 σ = 150.5 nm ÷ 식각률 74.6 nm/s = 2.02 초
실측 판정 지연 = 510 ns  →  예산의 0.00003%
```

이보다 짧은 지연을 목표로 최적화하는 것은 모델 오차에 묻혀 측정조차 되지 않는다.

> 판정 1회 소요시간은 문맥에 따라 510 ns / 544 ns 로 다르게 기록돼 있다
> (`make_figures.py` 는 544 를 사용). 측정 조건(챔버 수·타깃)이 달랐던 것으로
> 보이나 어느 조건의 값인지 기록이 남아 있지 않다.
